# Security

Report vulnerabilities to chucktastictime@gmail.com or via GitHub issues: https://github.com/TheAbsentTourist/weather-web/issues

Do **not** include a NASA FIRMS `MAP_KEY` or your `config.json` in a report. Rotate a leaked key at https://firms.modaps.eosdis.nasa.gov/api/map_key/.

The plugin does not host user data. It has no dependencies beyond Node 18+, and credentials stay on the installer machine.
